# Characters and saved voices

## Create or edit a character

1. In the attached Flow project, open **Characters** in the left sidebar. Check the names and portraits already there. Open the matching card to edit it. If two entries could match, resolve which portrait the creator means. If the character is new, use **New Character** or the creation form shown in an empty panel.
2. For a new entry, supply one or two images of the same character. Flow needs at least one usable image. Use the creator's chosen reference if the editor accepts it. If a new image is needed, describe the character, including the agreed style and distinctive item, and follow the project's credit rules before generating it. If the creator restricted generation to one composer mode, make the image in that mode and then use it in Characters. Keep the existing portrait when the request is only to change a voice.
3. Enter the requested name. For a voice request, open **Select a voice**. Pick the named voice, or choose a matching preset when the creator has described the delivery and left the choice to you. Preview a preset when playback is available. If an exact voice was requested and is missing, report the available choices before changing its assignment. For a visual-only request, keep the current voice setting.
4. Apply a selected voice with **Add to Character** and save the card with **Done**. Reopen it and read back the saved name and voice label when relevant. If the requested voice is already saved, reuse it. If the picker is unavailable or the reopened card does not show the assignment, report what you can verify. After a reconnect, check that card before creating or applying anything again.

## Create a custom voice when requested

Use the native voice creator if the user requests a custom delivery. Start from the character's voice picker when it offers creation. Flow also documents a route through the Omni Flash composer under **Add → Voices → Create New Voice**. Preserve the character draft before navigating away.

Select a matching base preset. In the custom description, explicitly include the intended adult voice gender, pitch range, tone and pace even when the preset already displays a gender. Use the creator's wording and pronouns to establish the intended voice. For example, write “Adult female voice, gentle and warm, naturally low female register, relaxed pace and clear articulation.” A low register alone leaves the gender ambiguous. Keep accent or language choices aligned with the brief.

Name the voice so its intended delivery is recognizable. Preview a representative line when available, applying the credit rules to any paid preview. Save it, wait for it to appear as a saved option, select it, apply it to the character and save **Done**. Reopen the card to verify the assignment. A voice saved in the voice list still needs to be applied to the character. Report audio as unverified if Browser Use cannot convey the sound.

## Use the saved speaker in a shot

For a requested video, type `@` and the character name in the chosen native bar. Select the matching entry and verify the visible character reference. Give the exact dialogue and identify who speaks. Keep silent characters and an off-screen narrator distinct. For an explicit per-shot voice reference, Flow documents **Omni Flash → Video → Ingredients**, then **Add → Voices**. Select the matching single-speaker voice if the shot needs it. If the requested mode cannot attach a required reference, surface that before submitting.

When reviewing a clip, check the spoken words and speaker during playback. A visible voice label confirms the saved setting. Mark clip audio unverified if you cannot hear it.

## Keep a character silent under narration

Reuse the existing character's approved portrait image from the project as the visual ingredient. Attach a separate narrator voice from **Voices** and reuse that exact voice reference across all shots. Keep the character's saved voice on its card available for later dialogue. Use an image ingredient in the narrated shots to reduce the chance that the saved character voice drives mouth movement.

Call the narrator a Voiceover (V.O.) in a separate Audio section. Keep the silent character's mouth out of the camera's view: profile when still, a three-quarter rear view when moving or turning the head, and no changing facial expressions while the voice plays. Give a clear body action and an explicit hand position when props are nearby. Avoid repeated negative instructions about speaking. Use the V.O. pattern in [Native prompt patterns](flow-agent-messages.md). Check the actual ingredient types after reuse, because a reused prompt can bring back a voice-linked Characters entry.

If a rendered character lip-syncs to narration, repair that shot using the portrait image and separate narrator reference. Recheck the mouth during playback. Treat this reference choice as a mitigation to verify in the result.
